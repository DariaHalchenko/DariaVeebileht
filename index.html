MVP (Minimal Viable Product)

  1. MVP (Minimal Viable Product) on minimaalse funktsionaalsusega toote testversioon, mille eesmärk on katsetada ideed.
  2. Loodud nõudluse analüüsimiseks, tagasiside saamiseks ja strateegia kohandamiseks.
  3. Edukad näited: Spotify alustas muusika voogedastusteenusena, Airbnb kodude üürimise testina.
  4. MVP aitab vähendada riske ja jõuda kiiremini turule.
  5. Peamine eesmärk on mõista, kas toodet tasub edasi arendada.

Git ja kauged repositooriumid

  1. Git remote

    2. Git remote on Git käsk, mida kasutatakse kaugrepositooriumite juhtimiseks. Selle abil saab lisada (git remote add), kustutada (git remote remove), vaadata (git remote -v).

  2. Kohaliku repositooriumi loomine
    3. git init

    Käsu initsialiseerib uue Git-repositooriumi praeguses kataloogis.

  3. Failide lisamine repositooriumi
    4. git add .

    See käsk lisab kõik muudetud failid „staadiumisse“, valmistades neid ette kommiteerimiseks.

  4. Loomine kommiteerimiseks
    5. git commit -m "...."

    Käsk loob kommandeeringu, mis salvestab muudatused koos määratud sõnumiga.

  5. Muudatuste saatmine
    6. git push origin master

    Saadab kõik kommitid kohalikust peaharust repositooriumi

  6. Repositooriumi kontrollimine

    7. Avage oma repositoorium GitHubis, et veenduda, et muudatused on esitatud.
